TTCK Apps Script patch - 2026-07-06

Current deployed symptoms:
1. Version 20260706-gmail-query-fallback-time-offset fixed Gmail search fallback.
2. LOG_SYNC now shows checkedMessages=29, so Gmail is being read.
3. But parsedOk=0 and parseFail=29, so the parser is failing on the current email format.
4. Old DATA_CK rows still show raw ACB time, e.g. 050726-20:24:37, because sync only appends new rows and did not migrate old rows.

Required deployed version after this patch:
20260706-parser-fallback-migrate-time

Fixes in apps_script_fixed.txt:
- matchAmount_ now falls back when CAI_DAT amountRegex does not match.
- matchAmountFallback_ supports Ghi co, Bao co, Credit, Nhan tien, Tien vao, +100.000 VND, So tien, Amount, Gia tri giao dich.
- extractContentFallback_ no longer requires exact marker 'Noi dung giao dich'; it can extract content around 'GD <code> ddmmyy-HH:mm:ss'.
- syncGmailByDaysLocked_ logs fixedTimes.
- fixExistingTransactionTimes_(settings) scans DATA_CK and corrects existing rows that still equal the raw ACB timestamp.
- buildTxInfo_ applies transactionHourOffset, default 1.
- readSettings_ now returns transactionHourOffset.

Expected after deploy and Cập nhật 7 ngày:
- LOG_SYNC: checkedMessages > 0
- parsedOk should increase if emails are ACB/TTCK format
- fixedTimes should be > 0 once if old DATA_CK rows need +1 hour
